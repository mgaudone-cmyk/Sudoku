# Sudoku App

A single-file Sudoku web app built with HTML, CSS, and JavaScript.

## Features

- Works in desktop and mobile browsers
- Optimized for iPhone Safari
- Difficulty selection
- Notes mode
- Mistake tracking
- Timer
- Auto-pause when the app loses focus
- Resume overlay
- Hint, check, erase, and solve controls

## Deploy on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` to the root of the repository.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Save.
6. Open the GitHub Pages link.

Your app URL will look like:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/
```

On iPhone, open the link in Safari and choose **Share > Add to Home Screen**.
