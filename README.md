# Sudoku App

A single-file Sudoku web app ready for GitHub Pages.

## Features

- Real Sudoku generator with unique-solution puzzle creation
- Difficulty levels: Easy, Medium, Hard, Expert
- iPhone-friendly responsive layout
- Add to iPhone Home Screen support
- Timer
- Auto-pause when app loses focus
- Resume overlay
- Mistake tracking
- Notes mode
- Hint button
- Check board button
- Solve puzzle button
- Highlights matching visible numbers when a number is selected or entered

## Files

- `index.html` — the full app
- `README.md` — this file

## Deploy on GitHub Pages

1. Create or open your GitHub repository.
2. Upload `index.html` and `README.md`.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Save.
6. Open your app at:

```text
https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/
```

For your current repo, the expected URL is:

```text
https://mgaudone-cmyk.github.io/Sudoku/
```

## iPhone install

1. Open the GitHub Pages link in Safari.
2. Tap the Share icon.
3. Tap **Add to Home Screen**.
4. Name it `Sudoku`.
5. Tap **Add**.
